# 🏦 Bank Management System (C++)

A console-based Bank Management System built using **C++** to strengthen object-oriented programming (OOP) concepts and improve problem-solving and system design skills.

## 🚀 Features
- 👤 Client management (Add, Update, Delete, Find)
- 🔐 User authentication system (Login/Register)
- 💸 Transactions (Deposit, Withdraw, Transfer)
- 📊 Display clients in a formatted table
- 💰 Calculate total balances (numbers + words)
- 💱 Currency exchange and calculator
- 🧾 Transfer logs tracking

## 🛠️ Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling (.txt storage)

## 💡 Purpose
This project was built to practice:
- OOP design and structure
- Working with multiple classes
- Handling real-world system logic without relying on UI frameworks

## 📌 Notes
- The system uses text files as a simple database
- No graphical interface (console-based)
